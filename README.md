# saxo-login

Pagina di redirect per il login Saxo (demo) del bot [personal-trader](https://github.com/xFra96/personal-trader).
Dopo il login dal telefono riapre Telegram e passa il codice al bot con `/start login_<codice>`.
La pagina non contiene segreti: lo scambio del codice richiede la chiave dell'app, che resta sul PC.
Indirizzo da registrare nell'app su developer.saxo: https://xfra96.github.io/saxo-login/
